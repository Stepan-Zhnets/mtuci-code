# Комманды Git

<table>
<tr>
    <td>Тема</td>
    <td>комманда</td>
    <td>Описание</td>
</tr>
<tr>
    <td rowspan=3>базаовые комманды</td>
    <td><code>git add .</code></td>
    <td>Добавляет изменения из рабочего каталога в индекс (или staging area) для последующего коммита</td>
</tr>
<tr>
    <td><code>git commit -m 'commit comment'</code></td>
    <td>Создает "снимок" проекта (коммит) и сразу же добавляет к нему краткое сообщение, описывающее сделанные изменения, без необходимости открывать текстовый редактор</td>
</tr>
<tr>
    <td><code>git push -u</code></td>
    <td>Отправка фиксаций на удалённый репозиторий (GitHub)</td>
</tr>
